### 1. 本義/轉義/辯證/音源/釋義未完全照原文
**认定（证据）**
- `tools/fix-shiyi.py` 首跑比对 22,827 条原稿行，violations **2247 处**，实际修 **1964 张**族卡 `shiyi`（余 291 张是带 `{{}}` 占位，属正常）。
- 五种常见形态：①整段被摘要改写；②栏首标签没剥（買 的 `benyi`、莽 的 `zhuanyi`）；③剥标签时 `split('：')` 把段内「《集韻》：“…”」切断（`e90c610ec` 修 11 张）；④《說文》句内形被删后文字连排；⑤`paras` 字段残留旧文本，页面仍显旧句。

**根因**
- 我按“理解后复述”写卡，而规矩是“逐段照录、只剥栏首标签”。
- 无校验：`check-shiyi.py` 只覆盖族卡 `shiyi`，五栏（本義/轉義/辯證/音源）无自动比对；`paras` 与 `text` 双份数据，改一份没改另一份。

**加固**
- 五栏一律按“标签段→下一标签段”整段照录；剥标签只用行首正则 `^(本義|轉義|辯證|音源|字形|字族衍義|聲母擬態|所属卷|釋義)[：:]`，**禁止 split 冒号**。
- 改卡同时改 `text` 与 `paras`（或整体删除 `paras`），改后跑 `check-cardhygiene.py`。
- 新建 `tools/check-cols.py` 的设想未落地（该脚本不存在，别再引用）；现用 `verify-card --expect` 或一次性 docx 段落 diff 代替。

- 抽图统一走 `blobs(i)`：段内 blip 全部取出存 `glyphs/inline/<字>/<栏>/NN.ext`，并在原文 run 位置写 `{{<栏>/NN.ext}}`；栏 section 设 `gdir='inline/<字>'`（卡顶层无效）。

**认定（证据）**

**加固**

### 10. 族表行被多包一层 → 站内 SPA 整页报错（2026-11-23 宿）
