# 释字方法：先定性，再释形义

《系统汉语》按「章—卷—部—字根—谐声字」组织全书。释一个字，必须沿这个结构走：先判断它在结构里的位置，再决定用哪套话讲。不能就字论字、只查字头。

## 二、四步流程

### 第 0 步 定位
查「全书目录与结构」主题（`knowledge/hanzi-origin/mulu.md`）：这个字是不是 609 部之一的部首字？属于哪一卷、哪一部？
同时确认同卷各部（音训）与同章各部（义训），因为它们可能提供平行的义证。

### 第 1 步 定性
- **是部名（部首字）** → 一级字根。
- **不是部名，但自身能滋生**（有以它为声符的字族、或条目称它为「音源字」）→ 二级／三级字根。
- **不是部名、也不再滋生** → 谐声字（末端衍生字）。

判据优先级：目录里有该部 ＞ 条目自称音源字 ＞ 存在以它为声符的字族 ＞ 条目只说「某声」。

### 第 1b 步 判六书（《系统汉语》绪论用班固名目，废「形声」）

定性之后必须紧跟一句六书判定。依据在「六书与造字理据」主题（`knowledge/hanzi-origin/liushu.md`）：

| 名目 | 判定标准 | 例 | Claim |
| --- | --- | --- | --- |
| 象形 | 独体，字形如图画，与所指之物相似，指具体一物 | 虎、六 | `clm_9D83C3A330303999E0CE97B82F` |
| 象事（指事） | 在象形字上加**无义指示符号** | 尤（又＋一撇，多出的手指）、刃 | `clm_D746084CE3DF7D4A806F4657C4`、`clm_BEEEC18A60BD7BBAE0C5C84496` |
| 象意（会意） | 两个以上**有独立意义的独体字**组合表义 | 反（厂＋又，攀崖） | `clm_20379AEF747D57A5148046DE9E` |
| 象声 | 即音源字，读音摹拟事物之声，形音义高度统一，是字根 | 虎（虎吼）、牛（牛鸣） | `clm_20E56E4B742D87857AF2DE01F2` |
| 假借 | 因义借声，按特征类比向音源字借音 | 六借虎音、某（梅）借母音 | `clm_3965DF271FA35D650097D3B8A5` |
| 转注 | 在声根上追加形旁，层层分化出新字 | 六→炉芦泸颅；王→㞷→匡→筐框诓 | `clm_5CD37BCFCBAB844C4DDCD1AD45` |

复合情况按绪论的六种组合报（`clm_7685A07CC2E86E6FA3DC13F04A`）：象形＋象声（牛、羊）、象形＋假借（日、月）、象事＋假借（尤、刃）、象意＋象声（杵、拓）、象意＋假借（尖、鲜）、象意＋转注（梅、蟙）。

三条纪律：

1. **不用「形声」这个词**（绪论主张抛弃许慎的形声概念，`clm_0A19B6204C47C4DDAFB4CFF402`）；由声根加形旁分化来的字，说「转注字」。库内「谐声字」是结构术语（部内谐声关系），不是六书名目。
2. 组合里哪一半是**音源**、哪一半是**构形**，要分开讲；音源那一半才算象声，字形那一半是象形／象意／象事。
3. 原书未直断的字（如「麝」），判决要标「据体例推」，与原文直断分开。

### 第 1c 步 声母义：拟态义要落到所指之物（2026-10-20 主人纠正）

报声母义不是报统计，是把绪论的拟态义拿到这个字所指的**物**上验一遍：

1. **取拟态义**：查「声母义（分部）」主题，得声母、部位、拟态义、部级一致度。
2. **落到物性**：这个物有什么性、人怎么用它。例：柳条细长柔韧，可收拢成束、编成筐篮席——这就是 l 的「拢」；插地即活、截头平茬年年留条（头木作业法）——这就是 l 的「留」。
3. **落到文化用法**：折柳赠别、柳与留谐音，赠柳即挽留，而赠别本身是「离」——l 的「拢离」两端在柳身上同时成立。
4. **落到字族分工**：同部同部位的兄弟字各分担哪一端（柳／留／罶：聚留；离、漓：离散）。
5. **部级一致度只作旁证**：它只说该部声母统一不统一，不能代替单字解释；若部首字今读是假借音（如「卯」的 mǎo 是地支借读，音源本音近「柳」liǔ），统计会把假借音当成本音，这时须以音源本音与字族主流为准，并写明「这是纠正统计口径的推断」。

### 第 2 步 若是字根
按固定顺序讲：
1. **本义**：先用一句判六书写在此处（判法见第 1b 步），再讲字形所象（甲骨文、金文），一字一义，不掺引申。
2. **转义**：从本义出发的引申路径，一步一因，写明「因何而转」。
3. **衍生义／字族**：按义项分桶，每桶举代表字，说明该桶与字根义的连接。
4. **造字能力**：它滋生了哪些二级字根、各自再滋生什么（这是判断「一级／二级」的依据）。
5. **附字形图**：讲本义前先摆该字全部古文字字形（`web/public/glyphs/<字>/NN.png`，甲骨、金文、戰國、漢隸按序），逐形点出何者象何—本义就是从字形直接读出来的。
6. **声母义**：查该部在「声母义（分部）」主题（`knowledge/hanzi-yinyuan/02z-shengmu-yi.md`）的条目，报声母、部位、绪论拟态义与一致度（强／中／弱），再说明这个拟态义在部内字族里如何分工；**拟态义须按第 1c 步落到本字所指的物性与文化用法上**，不能只报统计；零声母诸部明说「不系拟态声母义」。

### 第 3 步 若是谐声字
1. **拆形**：从条目「从某从某」「从某，某声」定出声符与形符。声符必定指向一个部内字根，不能把这个字自己当字根。
2. **先释声符**：讲声符字根本身的本义、转义（不是重复该字的释义）。若声符是二级字根，继续上溯到一级字根，直到音源字。同时报该声符所属部的「声母义」（声母拟态义＋一致度），看它是否与该字的取义方向相合——相合是旁证，不合就照实说不合；拟态义如何落到物性，见第 1c 步。
2b. **声根取义优先本义**（2026-10-21 主人纠正）：转注字里声根给的是**本义**，不是引申义。若声根另有与本字**同读的专用义**（如「久」除 jiǔ 时间长外，还有 jiù「灼病也」——《正字通》引《六书本义》，见 `clm_C15CF121451A466FF332CB9FCF`），那个同读义就是本字所取的义。字书里「疚，久也」「久病也」一类是**声训**（同音为训），不等于义源；不要把声训当构形依据。通则：**用字根释其谐声字，先试本义，本义讲不通才退到转义**（2026-10-21 主人定）。
2c. **声旁取义的方式是比喻**（2026-10-21 主人再定）：谐声字里的声旁字根，一般不是把本义原封不动搬过来，而是**取其本义作比**，释文要读作「**象……一样**」。例：「疚」＝象被灸灼一样疼痛（不是真的被灸）；「玖」＝象被烧灼一样色黑（不是真烧过）。故 2b 的「取本义」须落实成「**取本义之喻**」：先写「象……一样」的比况，再由形符定其类、定其落点（疒→病，玉→美石）。凡谐声字释义，「声符给义」一句都要带「象……一样」，不要写成声根义的直接套用。
2d. **不可轻言「象声不取义」**（2026-10-21 主人三定）：声旁几乎都有实义，看着像拟声的字，多半是先取其实义、再作比喻——**实义与比喻义两层并存**。例：「轰」＝三车相聚，象意众车；车多而行疾，声才大，故实义是「众车」，比喻义是「声音大如众车行驶之声」。释字时先求声旁实义（本义或转义），写成「象……一样」；只有确实搜不出实义可系者（如纯记音的借音字），才写「借声」，并说明为何无义可系。不要用「象声、不取义」草草了结——这种情形很少。
2e-0. **比况只给「形旁＋声旁」的谐声字；字根本身一律本义直释**（2026-10-21 主人五定）：**解释字根时不能作比喻义解**。「舆」的本义就是两人对举抬车之状，「追」的本义就是跟在屁股后面跑——这是字（或会意兼声字）的本义直释，不是比喻。比喻义**只针对合成的谐声字**，即形旁＋声旁（字根）的字根衍生字，且限于声旁以**相似关系**进入者（疚＝象被灸灼一样疼痛、玖＝象被烧灼一样色黑）。凡属以下情形，判类一律写「本义直释，不作比况」，并把声旁所取的本义写清楚：①一级、二级、三级字根本身；②象意兼声字（声旁本义与会意直接合成，如舆＝车＋舁「两人对举」、具＝鼎＋𦥑「两手举鼎」、追＝辵＋𠂤「臀」）；③象形、象事、会意不涉声旁者。不可泛泛地把「声旁取本义」一律写成「象……一样」。
2e. **比况只加在取本义的这一层**（2026-10-21 主人四定）：2c 的「象……一样」只用于**声根取本义**的场合；声根取的是**转义**时，直接说「取某某的转义」，**不再加一层比况**。例：「笨」＝取「本」（根干）的转义「内里、本体」；「監」「臨」「農」的引申义同理只是取转义，不写「象……一样」。判类句照此分写三类：取本义作比况（象……一样）／取转义（不加比况）／象意兼声（声旁兼表声与义，也不必都套比况）。已入库各条即按此口径，无须回头改。
3. **再释形符**：形符表什么，它与字根义在哪一点上接得上。
4. **合成**：该字含义＝声符义与形符义的交点；写清楚「声符给义、形符定落点」。
5. **横向对照**：同声符、不同形符的兄弟字（如胎／始），说明形符如何改变落点。
6. **附字形图**：声符字根与形符的古文字字形一律附上，图取自 `web/public/glyphs/<字>/NN.png`（原书抽出，图内小字自带出处与分期；`web/public/glyphs/index.json` 有 `doc` 与 `variants`）。只有字根有图、被释字无图时（如「渴」只有戰國文字），以字根图为主、并说明字形上声符与形符的位置。

### 第 4 步 证据分级
- 库内 `lifecycle=active` 且 `permission=public` 的 Claim：可作依据，带 `clm_` 出处。
- 库内条目之间的推断：写明「据……推」，不当作原文。
- 库外知识（《说文》等尚未录入者）：标明「库外，不作依据」，不得用来兜底。

## 三、示例：「始」

- 定位：目录无「始部」→ 非一级字根；属卷二·㠯部（第 8 部）。
- 定性：「始」从女台声；「台」亦非部名，台从口㠯声，而台自身滋生始、胎、贻、饴、炱、鲐、怡、咍、怠、殆等 → 台为二级字根，「始」为三级（末端谐声字）。
- 声符链：㠯／厶（一级字根，音源字，雄性生殖器象形，本义雄性、父系）→ 台（口＋㠯，象性交状态；致孕 → 胎儿、后嗣，《集韵》「嗣古作台」）→ 始。
- 形符：女——受孕生育的承担者。
- 合成：台给「致孕」义，女定「所从出之人」这一落点，故始＝女之初＝受孕怀胎之始；再由「生命之始」引申为一切开端。
- 对照：胎从肉台声——同一「致孕」义，形符「肉」取所成之实体，形符「女」取所起之时点。一实体、一时点，差别全在形符。

## 四、反例（本人踩过）

- 只用 `knowledge-search "始"` 搜字头，回 2 条便断言「库里没有解释」。实际解释在台部「字族按四义项分布」条内以举例形式存在——谐声字的释义从来不挂在字头下，而挂在所属字根的部里。
- 结论：**查字先查声符，再查部，最后才查字头。**

## 五、落地位置（2026-10-20 已实现）

- 字卡已改成七栏：**分级 → 声母义 → 字形 → 字根 → 本义 → 转义 → 衍生字义**。分级栏由服务端 `web/server.mjs` 的 `levelOf()` 判定，模型不得改动；声母义栏由 `shengmuOf()` 读「声母义（分部）」主题文件注入，同样不由模型改写。`CARD_PROMPT` 第 0、0b 条要求模型先交代级别、并只引用系统给的声母义。
- 六书**不单列一栏**（2026-10-20 主人定）：判语写进「本义」一栏的开头一句，`CARD_PROMPT` 第 3 条给出判法（班固名目，不用「形声」；构形与音源分两截判，如「象意＋象声」；判不出就不判），本义栏上限放宽到 170 字。服务端 `ensureLiushu()` 把开头归一成「六书：……」，模型写成「象意：」或「转注。」也统一补齐。实测：射＝象意＋象声、鹿＝象形＋象声、龍＝象形＋象声、士＝象形。「麝」因条目只记「射族」、没记「从鹿䶶声」，模型只判出「象声」——要使它判成「象意＋转注」，得在条目里补上形符那一句。
- 判级数据来自 `tools/zigen-index.mjs` 生成的 `web/public/zigen.json`（608 部 / 100 卷 / 12 章，缺第 223 部、第 554 部部首字未转录）；判级线索依次是：`byName`（部名）→ `variantOf`（异体隶变，如「以」之于「㠯」）→ `findRoot`（条目「从某声」）→ `familyOf`（「X部：字族…」条目）→ `spawnsFrom`（有「X部」条目、自称音源字、或别的字「从 X 声」）决定「二级／三级」还是「谐声字」。
- 人工释字（本文件的流程）现在应与这套判级结果一致：先报「一级／二级／三级字根／谐声字＋声符链」，再按第 2 步或第 3 步展开。
- 字根字形随卡自动附出（2026-10-20 主人要求「凡是涉及到字根，只要库里有古文字图形，都要显示出来」）：`levelOf()` 的结论带 `chainChars`，`handleCard` 收集其中异于本字的字根字形放进 `card.roots`，前端在字形行下逐条列出「字根「X」的古文字字形」；本字无字形行时（「始」「胎」）只给字根图并注明是声符字根，本字与字根同批图（「以」之于「㠯」）不重复。人工释字同样遵守：讲到哪一级字根，就把那一级的图摆出来。
